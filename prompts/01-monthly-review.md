# 月次レビュー

税理士事務所の月次チェック用です。まずは読み取り専用で月次の状態を集め、月次レビュー表を作ってください。修正や登録はしません。

## 進め方

1. 対象の事業所と対象月を確認する。必要なら会計年度も確認する。
2. API を呼ぶ前に、使う path と HTTP method を先に説明する。例として、`GET /api/1/reports/trial_pl` は損益の確認、`GET /api/1/reports/trial_bs` は残高の確認、`GET /api/1/journals` は仕訳帳の出力要求、`GET /api/1/manual_journals` は振替伝票の確認に使う。
3. まずは月次の全体像を読む。次に、差異が大きい科目や不自然な増減だけ深掘りする。
4. 集計結果は表で並べる。科目ごとの前月差、前年差、件数、気になる点を見える形にする。
5. 異常値や説明がつかない増減は `要確認` に入れる。理由も一緒に書く。
6. 直す必要がありそうでも、その場で書き換えず、人の確認を待つ。

## 重点確認

- 損益の大きな増減
- 残高の急な変化
- 仕訳や振替伝票の不自然な集中
- 証憑や経費申請との突合でずれるもの

## 出力の形

- 月次サマリー表
- 科目別の差異表
- `要確認` 一覧
- 人への確認事項

## 書き込みの扱い

- `POST` `PUT` `PATCH` `DELETE` は使わない
- 修正案が必要な場合は、API path と HTTP method を明示したうえで、実行前に承認を取る

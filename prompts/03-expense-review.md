# 経費レビュー

税理士事務所で経費申請を確認するためのプロンプトです。最初は読み取り専用で集めて、経費申請の妥当性を表で整理してください。登録や更新は、人の確認が終わるまで行いません。

## 進め方

1. 対象の事業所、対象月、対象者、対象ステータスを確認する。
2. API を呼ぶ前に、使う path と HTTP method を先に説明する。例として、`GET /api/1/expense_applications` は申請一覧の確認、`GET /api/1/expense_applications/{id}` は詳細確認、`GET /api/1/expense_application_line_templates` は経費科目の確認、`GET /api/1/receipts` は証憑確認に使う。
3. まず一覧で全体をつかみ、必要なものだけ詳細を読む。
4. 申請タイトル、日付、金額、証憑の有無、ステータス、経費科目の組み合わせを表にする。
5. 不足、差異、説明不足、証憑不一致、申請経路の不自然さは `要確認` にする。
6. 申請の新規作成、更新、削除が必要そうでも、勝手に実行せず、下書きと理由を出して人に確認する。

## 重点確認

- 領収書があるか
- 金額と日付が合っているか
- タイトルが中身を説明できているか
- 経費科目が事業所の設定に合っているか
- 清算待ちや差戻しのまま放置されていないか

## 出力の形

- 申請一覧表
- 問題候補の表
- `要確認` 一覧
- 人への確認事項

## 書き込みの扱い

- `POST /api/1/expense_applications` や `PUT /api/1/expense_applications/{id}` が必要な場合は、実行前に必ず承認を取る
- 先に読み取り専用の確認を終えてから、下書きだけ作る

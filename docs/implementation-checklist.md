# 実装チェックリスト

このチェックリストは、税理士向けの安全利用を前提に、段階的に実装を進めるためのものです。

## 導入前

- [ ] freee 利用状況を確認する
- [ ] 利用する freee サービスを確認する
- [ ] 対象業務を確認する
- [ ] 顧問先データの取り扱いルールを確認する
- [ ] freee アプリ作成権限を確認する
- [ ] Codex を利用する PC 環境を確認する
- [ ] Node.js、Bun、Git の有無を確認する

## 接続時

- [ ] freee アプリを作成する
- [ ] コールバック URL を設定する
- [ ] Client ID / Client Secret を取得する
- [ ] `npx freee-mcp configure` を実行する
- [ ] OAuth 認証を行う
- [ ] 事業所を選択する
- [ ] Codex MCP 設定を追加する
- [ ] 認証状態を確認する
- [ ] 事業所一覧を取得する
- [ ] 現在の事業所を確認する

## 初回検証

- [ ] 取引一覧を取得する
- [ ] 取引先一覧を取得する
- [ ] 勘定科目一覧を取得する
- [ ] 請求書一覧を取得する
- [ ] freee 画面との照合を行う
- [ ] エラー記録を残す
- [ ] 操作ログを記録する

## 運用設計

- [ ] 読み取り専用ルールを決める
- [ ] 下書き作成ルールを決める
- [ ] 登録前確認ルールを決める
- [ ] 削除禁止ルールを決める
- [ ] 顧問先別の運用ルールを決める
- [ ] スタッフ権限を決める
- [ ] 月次レビュー手順を決める

## 実装時の確認項目

- [ ] 対象会社が意図したものか
- [ ] 対象期間が正しいか
- [ ] 件数が想定内か
- [ ] 金額の桁や符号が正しいか
- [ ] 削除や上書きが含まれていないか
- [ ] 人の最終確認が必要な状態になっているか
- [ ] ログに不要な個人情報が残っていないか

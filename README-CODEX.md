# README-CODEX

このファイルは、freee-mcp を Codex Desktop から使うための非公式スターターキットです。
freee 公式の案内ではなく、またフリー株式会社による承認、保証、サポートを示すものでもありません。

対象は、税理士事務所の担当者、freee 利用者、AI 導入を手伝う人です。
まずは読み取り専用で安全に始め、必要なときだけ人間が確認して書き込みへ進む前提でまとめています。

## 目的

- Codex Desktop から freee-mcp を使いやすくする
- まずは読み取り中心の使い方を定着させる
- 登録、更新、削除の前に人間確認を必須にする
- 税務判断の最終責任は人間にあることを明確にする
- 公式と誤認されない説明にそろえる

## 非公式であること

このリポジトリは、freee-mcp を Codex で使うための補助資料です。
freee とは別の非公式資料です。
freee、freee会計、freee人事労務、freee請求書、freee工数管理、freee販売、freeeサインの名称は、各権利者の商標または登録商標です。

## Codex Desktop でできること

- ローカルの README、手順書、設定例を読みながら作業できる
- MCP 経由で freee の事業所、ユーザー、取引、勘定科目、請求書などを参照できる
- まずは読み取り専用の確認から始められる
- 変更前に差分案を作らせて、人間が確認してから反映できる
- 業務メモや操作手順を、日本語で整理しながら扱える

## 最初は読み取り専用で使う

最初の確認は、次のような読み取り系から始めるのが安全です。

- 事業所一覧の確認
- 現在の事業所の確認
- ユーザー情報の確認
- 取引一覧の確認
- 取引先一覧の確認
- 勘定科目一覧の確認
- 請求書一覧の確認

この段階では、登録、更新、削除を依頼しないでください。

## 人間確認が必要な操作

次の操作は、必ず人間が内容を見てから進めます。

- 新規登録
- 更新
- 削除
- 事業所の切り替え
- 税区分や勘定科目の確定

Codex が提案しても、最終実行は人間が承認してからにします。

## 税務責任

Codex は補助役です。
仕訳、税区分、申告、請求、経費、控除の判断は、必ず人間が確認してください。
最終的な税務判断と提出責任は、人間にあります。

## セットアップの流れ

1. [docs/codex-setup.md](./docs/codex-setup.md) を見て、Bun と依存関係を入れる
2. 必要なら freee のアプリ連携設定を行う
3. [docs/codex-mcp-config-example.md](./docs/codex-mcp-config-example.md) を参考に Codex Desktop へ MCP を登録する
4. `bun run dev` などでローカルの MCP サーバーを起動する
5. まずは読み取り系の依頼だけを試す
6. 書き込み系は必ず人間確認を挟む

## Codex での使い方

Codex には、最初は短く具体的に依頼します。

例:

- 「事業所一覧を取得して、今の事業所名を日本語で要約して」
- 「取引一覧を読んで、件数と主な項目だけまとめて」
- 「この変更は書き込みが必要か、先に確認して」

運用の基本は次の通りです。

- 読み取り系から始める
- 書き込み前に必ず人間が確認する
- 迷う操作は実行しない
- 税務判断は Codex に任せない

## よくあるトラブル

- Codex で MCP が見つからない
  - `docs/codex-mcp-config-example.md` の設定内容を見直し、Codex Desktop を再起動してください。

- 認証が通らない
  - `npx freee-mcp configure` をやり直し、ブラウザでの認証まで完了してください。

- 事業所の不一致で止まる
  - 現在の事業所と `company_id` の指定を見直してください。

- 依存関係の不整合が出る
  - `bun install` の後に `bun run build`、必要に応じて `bun run typecheck` を試してください。
